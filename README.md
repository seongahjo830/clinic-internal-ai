# 서울사계절치과 내부 AI · 내규 위키

직원이 우리치과 내규·운영 규정·임상 위키를 근거로 질문하고, 자료를 추가하고, 위키로 바로 보는 내부용 도구입니다.

- 💬 **질문하기**: 내규 기반 AI 답변 (Claude API 키 입력 시) / 키 없으면 관련 자료 검색
- 📚 **위키**: 카테고리별 내규·SOP 열람
- ➕ **자료 추가**: (치과의사·실장 모드) 드래그드랍 업로드 + 교육 기록

> ⚠️ 인물명은 직책으로 익명화되어 있습니다. 검색엔진 비노출(noindex) 처리.
> AI 답변을 켜려면 화면 우측 상단 ⚙️ → Claude API 키 입력 (키는 사용자 브라우저에만 저장).
